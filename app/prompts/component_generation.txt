ANTI-REPETITION RULE

Avoid:

- repeating the same card-array structure as the primary composition
- creating identical hero-copy + 3-stat layout blocks across multiple scenes
- using the same visual rhythm for every scene

Use variation deliberately. A video feels premium when scenes have distinct visual logic while still sharing a coherent brand language.

ApprovedAsset receives:

- manifest
- optional fit
- optional style
